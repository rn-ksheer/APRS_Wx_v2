# 📡  APRS_Wx_v2 Powered by Python

## NO HARDWARE NEEDED 
no hardcoding, no sketch modifications, and absolutely no library dependency. :trollface: <br>
lightweight and Configurable using any other text editor. 😃

### configuration steps:
>- Open **config.ini** in any __text editor__
>- Add your station's latitude and longitude
>- User callsign
>- Passcode for APRS
>- Time interval in minutes
>- Save file & run it by double clicking
